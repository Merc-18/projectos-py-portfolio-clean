# G-001 — Aplicación Streamlit de formularios ficticios

**Alternativa demostrativa completamente independiente** del desarrollo original: muestra formulario web y genera PDF de muestra, con marca **DEMO - SIN VALIDEZ OFICIAL**.

No utiliza plantillas de empresa, tarifas, identificadores, Excel corporativos, COM de Windows ni datos personales. No busca replicar los documentos originales. El código contiene un generador PDF ejecutable independientemente de Streamlit y una interfaz opcional.

```bash
pip install -r requirements.txt
python generate_pdf.py demo.pdf --descripcion 'Registro ficticio' --monto 45.00
streamlit run app.py
```

La salida PDF no se sobrescribe. Solo para datos ficticios. El código original no está publicado ni se ha copiado a esta carpeta. La publicación pública del portafolio requiere autorización.
