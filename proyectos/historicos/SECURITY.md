# Security and publication control

**This is a private preparatory copy. Not approved for public publication.**

- Historical input files, customer data, internal folder names, network endpoints,
  passwords, signatures and AI keys are excluded.
- Two historical records remain fully reserved and unlisted.
- Safe examples are independent, offline reconstructions, NOT exact copies of private code.
- All output operations require explicit input/output parameters.
- File-copier demonstrations are dry-run by default; `--execute` copies PDFs only
  and refuses to overwrite an existing destination directory.
- Historical duplicates are represented by links, not redundant source files.
- Dependencies are optional per mode. OCR requires local Tesseract software.
- Never run demos on confidential data or reuse prior Git history.
