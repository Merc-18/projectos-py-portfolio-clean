# Puerta de seguridad — NO PUBLICAR AÚN

Este repositorio privado utiliza un historial propio, iniciado con un commit raíz independiente. Tiene commits nuevos de mantenimiento y migración, pero no comparte historia con el repositorio empresarial. Eso no sustituye las demás verificaciones:

- [ ] Confirmar que el uso de cada demo y cada código adaptado y su documentación está autorizado.
- [ ] Revisar todas las dependencias y licencias de terceros.
- [ ] Revisar los 103 títulos y descripciones antes de exponerlos a terceros.
- [ ] Inspeccionar el contenido, rutas, comentarios, metadatos y el historial Git completo de la copia final.
- [ ] Confirmar que no se han incorporado datos reales o credenciales.
- [ ] Confirmar que las seis fichas reservadas de código siguen sin fuentes.
- [ ] Comprobar que los dos registros históricos reservados no se muestran.
- [ ] Obtener aprobación expresa para hacer público el repositorio y/o habilitar un sitio web.

**No** debe convertirse el repositorio antiguo ni el repositorio de preparación en público. Mantener este repositorio privado, verificar el historial completo y aprobar cada archivo antes de cualquier transición a público. Una revisión negativa obliga a reconstruir otra copia limpia.
